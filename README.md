# Classic French Opera Cake – HTML Recipe PageHTML-based recipe webpage** presenting a **Classic French Opera Cake (Gâteau Opéra)**.
It was developed as part of **Assessment 1** to demonstrate understanding of **core HTML concepts**, structured content, proper use of lists, images, text formatting, and clean, readable markup.

The page follows **professional culinary documentation standards**, using **metric measurements** and a clear, sectioned layout suitable for instructional or portfolio use.

---

## 🎯 Project Objectives
The objectives of this project are to:

- Demonstrate correct **HTML document structure**
- Use **semantic and structural elements** to organise content
- Display information using **ordered and unordered lists**
- Include **images with appropriate attributes**
- Apply **text-formatting elements** for emphasis and clarity
- Produce **valid, readable HTML code**

---

## 🧁 Recipe Details
- **Recipe Name:** Classic French Opera Cake (Gâteau Opéra)
- **Cuisine:** French Pâtisserie
- **Difficulty Level:** Advanced / Professional
- **Prep Time:** 90 minutes  
- **Cook Time:** 10 minutes  
- **Chill / Set Time:** 2–4 hours  
- **Servings:** 18–20 portions
- **Measurement System:** Metric (International Standard)
